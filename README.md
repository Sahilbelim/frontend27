## 📖 About  

This repository contains **examples, notes, and demos** for building modern web applications.  
It’s structured into separate folders to help you learn and practice different parts of the web stack step by step.  

---

## 📂 Folder Structure  

### **bootstrap/**  
Experiments and mini projects built using the **Bootstrap framework** (layouts, grids, components).  

### **css/**  
Examples and practice files covering **CSS fundamentals**, selectors, styling techniques, and responsive design.  

### **html/**  
Basic **HTML exercises and lessons** to understand core markup structure.  

### **html5/**  
Advanced **HTML5 elements**, form controls, media, and navbar demos.  

### **javascript/**  
JavaScript practice projects, exercises, and utility scripts.  

### **nodejs/**  
Simple **Node.js experiments** and backend practice files.  

### **parallax/**  
Experiments with **parallax scrolling effects, navigation menus, tabs & pills** UI.  

### **pdf/**  
Contains some **PDF notes** related to CSS and web development.  

---

## 📄 Text Notes  

The repo also includes **learning notes and references** in plain text format:  

- **all about input.txt** → Notes about different HTML input elements  
- **extension.txt** → General notes on browser/dev extensions  
- **firefox extensions.txt** → A list of useful Firefox developer extensions  
- **useful links.txt** → Collection of helpful online resources and documentation
